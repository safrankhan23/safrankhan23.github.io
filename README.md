# Safran Khan Academic Website

A static academic website designed for free hosting with GitHub Pages.

Main pages:

* `index.html` for the home page, About Me, research interests, education, and projects
* `news.html` for academic news and research updates
* `publications.html` for publications and manuscripts
* `conferences.html` for conference presentations and posters
* `contact.html` for contact information and academic profiles
* `assets/styles.css` for design, layout, light mode, and dark mode
* `assets/site.js` for the theme switcher
* `assets/profile.jpg` for the profile photo
* `assets/Safran_Khan_CV.pdf` for the CV

The site is ready for GitHub Pages.
